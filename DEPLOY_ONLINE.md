# Deploy MagLoss Studio on Streamlit Community Cloud

1. Create a GitHub repository, e.g. `magloss-studio`.
2. Upload the files in this folder to the **root** of the repository: `app.py`, `engine.py`, `requirements.txt`, `demo_synthetic_data.csv`, and `README.md`.
3. Go to https://share.streamlit.io and sign in with GitHub.
4. Select Create app > Yup, I have an app.
5. Choose your repository, branch `main`, and main file `app.py`.
6. Optionally select a free subdomain, and click Deploy.
7. Share the resulting *.streamlit.app link.

Note: The included sample data is synthetic. Verify models against measured data before engineering use.
